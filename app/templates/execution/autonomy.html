Agent autonomy

How far each agent may go on its own. Agents propose a plan for every artifact; this setting decides how much of that plan could run without you. In this release plans are suggestions only — nothing executes, whatever the level.

  • Sending, signing, posting and trading always need your explicit confirmation, at every level.
  • Full autonomy (L4) is not available.
  • Wealth Deployment (Layer 5) agents only generate advisory documents; they never execute.
  • Money movement (the DCA schedule's trades) is disabled.
